v8 更新了什么

在 v7 的结构基础上，v8 把公开 BOM 锚点放进主图：GPU/CPU 量产价估算、20.7TB HBM4/rack、54TB LPDDR5X/rack、3D NAND 约 $1M+/rack、液冷约 $49,860/rack。

同时保留口径边界：HBM 属于 GPU COGS，LPDDR5X 和 NAND/SSD 属于 Host server hardware；memory/storage $2M/rack 是混合估算，不直接画成一个单独节点。
