  • 公司将砷化镓产线从北京搬迁至外地，因产线调试、员工熟练度等问题导致报告期内产品毛利率出现较大波动。
  • 公司面临来自Sumitomo、Umicore等国际企业和云南锗业等国内厂商的激烈市场竞争。
主要风险
  • 公司与控股股东AXT分别在科创板和纳斯达克上市，需遵循两地不同法规，可能因《外国公司问责法案》等因素导致AXT面临退市风险，从而影响本公司。
  • 对部分关键原材料供应商存在依赖，且原材料价格波动可能对公司业绩产生较大影响。
  • 工厂搬迁导致产品毛利率出现波动，新生产线存在无法稳定达产或良率未达预期的风险。
  • 锗衬底等产品面临国内竞争对手进入导致的价格竞争加剧风险，可能导致市场份额降低或毛利率下降。
  • 中美贸易争端加剧可能导致公司采购的原材料或设备成本上升、出口产品被加征关税，对经营产生不利影响。
  • 砷化镓衬底在部分应用领域存在被绝缘体上硅（SOI）等其他新兴技术替代的风险。
