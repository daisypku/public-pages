CritICL: Inference-Time Weak-to-Strong Generalization from Small Language Model Failure Modes

研究问题：大型语言模型（LLMs）的推理性能提升通常依赖重复生成或外部验证，这限制了其效率。

方法：提出CritICL框架，利用弱模型在推理时的失败模式作为指导。CritICL-dynamic自适应预测输入特定的失败模式并检索批评，而CritICL-static则使用全局失败模式配置文件提供稳定指导，将这些批评作为上下文示例融入推理过程。

结果：CritICL持续优于标准上下文学习，并在性能上与测试时扩展方法相当或更优，同时显著减少了生成次数和token成本。

为什么重要：该方法在保持高效率的同时，显著提升了LLM的推理性能，为推理时扩展提供了一种新颖且高效的思路，尤其适用于资源受限的场景。

局限：论文未明确提及，但可能存在弱模型失败模式的识别准确性、以及对不同模型家族和任务的泛化能力等潜在局限。

WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution

研究问题：AI Agent从经验中自动发现技能，但指导技能发展的见解通常分散在优化历史中，限制了其在迭代间的系统性重用。

方法：引入WikiSkill框架，使Agent技能与持久知识库（wiki）共同演化。该框架将原始执行经验、积累知识和可执行技能分离，并持续将经验整合到wiki中，供后续技能更新构建。

结果：WikiSkill在多样化的基准和模型上持续优于现有技能演化方法，并发现技能演化与模型扩展互补（更大的模型通常从演化技能中受益更多），且演化技能可有效跨模型和模型家族迁移。

为什么重要：解决了Agent技能经验重用问题，通过系统性积累和提炼经验，显著提升了Agent技能的可重用性和可迁移性，使Agent能更有效地适应和学习，甚至小模型在拥有技能后能超越无技能的大模型。

局限：论文未明确提及，但知识库的维护成本、知识冲突解决机制、以及在极其复杂或快速变化环境中的适应性可能需要进一步探索。

SWE-Prime: Fewer Trajectories, Better Performance

研究问题：为提升大型语言模型（LLMs）解决实际软件问题的能力，现有方法通常对成功的Agent轨迹进行监督微调（SFT），但成功轨迹可能包含低效、冗余或有风险的步骤，从而引入噪声监督。

方法：提出SWE-Prime，一种多粒度、两阶段的SFT数据选择方法。第一阶段基于过程质量、结果质量和数据代表性进行轨迹级筛选；第二阶段将连续步骤分组为语义片段，评估其对最终解决方案的贡献、可学习性和潜在风险，仅选择的片段参与损失计算。

结果：在SWE-Bench Pro和SWE-Bench Verified基准测试上，使用SWE-Prime选择的10%轨迹子集进行训练，性能优于使用完整已解决数据集训练，相对性能提升高达12.2%和24.2%。

为什么重要：通过精炼训练数据，减少噪声监督，使模型学习更有效的解决行为，显著提高了LLM解决实际软件问题的能力，并降低了训练成本。

局限：论文未明确提及，但筛选标准的主观性、对不同类型软件问题的泛化能力、以及如何自动化和优化筛选过程可能存在局限。

TTPO: Test-Time Policy Optimization

研究问题：强化学习（RL）和On-Policy Self-Distillation（OPSD）等后训练方法依赖真实标签，无法进行测试时训练（TTT），而使用多数投票伪标签作为替代则非常脆弱，易受错误影响。

方法：提出Test-Time Policy Optimization (TTPO)，一种非对称目标函数。它通过OPSD蒸馏与伪标签一致的rollout，并用Grouped RL惩罚与伪标签不一致的rollout。令牌级选择进一步细化两个分支，确保即使在伪标签错误频繁的情况下更新也能保持稳健。

结果：在没有任何标签的情况下，TTPO在五个竞赛级基准测试上与标签监督的OPSD表现相当，在TTT中将Qwen3-1.7B的性能从38.0%提升到45.2%，并显示出强大的跨任务泛化能力。

为什么重要：实现了无需真实标签的测试时策略优化，显著提升了LLM在数学推理等任务上的性能，降低了对昂贵标签数据的依赖，提高了模型的适应性和泛化能力。

局限：论文未明确提及，但伪标签的质量对TTPO性能的影响、以及在更复杂或开放域任务中的表现可能需要进一步验证。

From Static to Dynamic: Benchmarking Real-World Code Review with MCR-Bench

研究问题：现有大型语言模型（LLMs）自动化代码审查方法将代码审查简化为单轮静态决策任务，未能捕捉现实世界中多轮交互和复杂问题解决的本质。

方法：引入MCR-Bench，首个针对真实多轮代码审查的缺陷状态感知基准。该基准包含2,269个真实多轮代码审查任务，涵盖五种常用编程语言，并标注了细粒度缺陷信息和跨轮次状态标签。

结果：主流LLMs在缺陷检测和缺陷生命周期状态跟踪方面表现有限，随着交互轮次增加性能显著下降；性能因缺陷类型和严重程度而异；深入的错误分析揭示了跨轮次时间错位和长程记忆不足等关键弱点。

为什么重要：揭示了现有LLMs在真实多轮代码审查场景中的局限性，为未来研究提供了更真实、更具挑战性的基准，有助于开发更符合实际需求的自动化代码审查工具。

局限：论文明确指出了LLM的局限性，如整体能力有限、对缺陷敏感的性能差异、以及跨轮次时间错位和长程记忆不足等底层失败机制。

RedEvoAgent: Automatic Red-Teaming Agent with Experience-Driven Skill Evolution

研究问题：LLM Agent部署在产品级执行环境中，越狱可能触发有害工具使用和持久状态改变，其风险高于不安全文本生成。现有自动红队方法依赖固定攻击或轨迹检索，但后者可能重用误导性经验。

方法：提出RedEvoAgent，一个黑盒红队Agent，它将跨案例攻击轨迹提炼成简洁、人类可读的攻击技能。该攻击技能通过工具有效性分析和决策工具归因来适应性演化，并通过验证棘轮机制仅保留能提升验证性能的更新。

结果：RedEvoAgent在多个基准、目标模型和执行环境中优于固定和Agentic基线，提高了工具效率，并能在攻击者模型和目标执行环境之间迁移。

为什么重要：提升了LLM Agent的红队测试能力，通过自动演化攻击技能，更有效地发现Agent在产品级部署中的安全漏洞和潜在风险，从而增强了Agent的安全性。

局限：论文未明确提及，但黑盒攻击的效率、对新型越狱手法的适应性、以及技能演化过程的计算成本可能存在局限。

Stochastic Estimation of Transduced Language Models

研究问题：Transduced语言模型（TLMs）中计算目标前缀概率需要对源字符串进行求和，但该集合可能呈指数级大或无限，现有方法使用阈值剪枝束求和，产生误差未知的下界。

方法：提出一种无偏估计器，通过不放回重采样源前缀，并根据其包含概率的倒数重新加权。递归应用此校正，并扩展了束求和算法，减少保留的源前缀数量，同时保证运行以概率一停止。

结果：在百科文本和DNA上，该方法在计算-方差权衡方面优于顺序蒙特卡洛基线，在相同最大粒子数下误差更低。在DNA到氨基酸转导中，运行时比阈值剪枝束求和减少数个数量级，使得估计长目标字符串的前缀概率变得可行。

为什么重要：提供了TLMs目标前缀概率的无偏估计方法，解决了现有方法误差未知的问题，显著提高了计算效率，使得对长目标字符串的概率估计变得可行，并能更准确地评估语料库的惊奇度。

局限：论文未明确提及，但无偏估计器的方差特性、在特定复杂转导任务中的收敛速度、以及对不同源语言模型和转换器组合的适用性可能需要进一步评估。

Persona-Execution Separation: An Architecture Pattern for Evolving LLM Agents under Execution Audit

研究问题：受监管组织中的大型语言模型（LLM）Agent需要同时满足“角色（persona）自由演化”和“执行（execution）可追溯审计”的需求，单一信任域难以廉价地同时满足这两点。

方法：提出“角色-执行分离”（Persona-Execution Separation, PES）架构模式。该模式将角色和执行置于不同的信任域，并通过受治理的契约桥连接。角色可以自由漂移，而执行则保持无面且可审计。

结果：PES模式通过架构设计，实现了角色自由演化与执行可追溯审计的解耦。在受监管数字员工平台中的开发案例验证了该模式的有效性，确保了在角色扰动下执行侧无需重新验证，且执行路径与角色解耦。

为什么重要：为在受监管环境中部署LLM Agent提供了关键架构模式，解决了角色灵活性与执行合规性之间的冲突，确保了Agent在演化过程中的可信赖性和可审计性，同时降低了耦合成本。

局限：论文明确指出，任何单一信任域机制若要同时满足自由漂移、执行可追溯性和解耦这三个目标，都必须以更高的耦合成本重新引入类型化变更对象、外部门控和稳定审计锚点。

理解AI自我改进的深层机制和局限性，对于构建更可靠、更通用、更安全的AI系统至关重要。这有助于区分真正的智能进步与测量假象，并指导研究方向，以克服当前AI学习范式的固有缺陷，推动AI向更接近人类智能的持续、鲁棒学习发展。
