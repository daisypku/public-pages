One Basis to Animate Them All: Gaussian Blendshape Distillation for Real-Time Avatars

研究问题：3D高斯头像的实时动画因昂贵的神经推理而面临挑战。

方法：引入GALA（Gaussian Animation via Linear Approximation），一种蒸馏方法，将预训练头像模型的动画近似为与身份无关的混合形状的线性组合。通过浅层系数预测器和线性混合取代每帧繁重的神经解码。使用渲染感知度量和内存预算下的块局部PCA构建基底。

结果：将CPU动画成本降低了三个数量级，同时保留了大部分渲染质量，并能泛化到未见过的身份。在移动设备上实现了高达60fps的高效准确动画。

为什么重要：该方法通过显著提高效率，使3D高斯头像在资源受限设备上实现实时动画成为可能，并证实了学习到的头像表示中存在共享的线性结构。

局限：蒸馏方法本质上涉及近似，可能在某些情况下导致渲染质量的轻微损失。该方法依赖于预训练的头像模型，主要用于加速现有模型的推理而非生成新模型。

KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards

研究问题：现有的大型语言模型（LLM）评估侧重于知识或端到端代理任务，未能直接衡量LLM为真实世界网络安全工具生成可执行命令行接口（CLI）命令的能力，而CLI对语法要求严格。

方法：引入KaliBench，一个针对Kali Linux上自然语言到CLI转换的细粒度基准和数据集，包含8,504个查询-命令对，涵盖1,642个工具。通过手稿驱动的管道构建，具有确定性规范化和别名感知评估。开发了多阶段验证管道（LLM验证、沙盒执行、人工精炼）以确保语义正确性和可执行性，并支持运行时无关的可验证奖励训练。

结果：在无工具提示的非受限设置下，通用和安全专用开源模型在精确命令准确率上均未超过42%。使用KaliBench衍生的可验证奖励进行监督微调和强化学习，显著提升了8B模型性能，使其与685B MoE模型相当。

为什么重要：填补了LLM在网络安全领域应用评估的关键空白，为训练LLM生成精确、可执行的CLI命令提供了可靠的基准和方法，对实际网络安全操作至关重要。

局限：即使经过改进，模型在非受限设置下的准确率仍相对较低（42%），表明仍有很大的提升空间。基准主要针对Kali Linux工具。

Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents

研究问题：在多样化任务中构建可靠的机器人能力需要大量人工投入来开发和维护技能、设计奖励以及整合感知与控制。

方法：提出Reconstruct, Practice, Go Real (RPG) 框架，用于自主改进机器人执行系统，而无需更新模型权重。该框架从离线数据集中识别操作能力，并在模拟中构建相关练习任务。在练习过程中，RPG利用执行反馈、特权模拟器状态和可用数据集视频来诊断故障，开发新的可重用符号技能，完善现有技能，并根据诊断修改系统提示。在保留修订前，通过跨任务评估测试单个候选更改和合并修订。在测试时，多模态LLM使用生成的系统提示和技能库来协调感知和机器人控制。

结果：在22个操作任务的未见初始化上，RPG将任务成功率从第一轮练习后的28.6%提高到15轮后的95.0%，优于所有评估的基线（包括ASPIRE的75.5%和由GPT-6 Astra Pro驱动的CaP-Agent0的60.0%）。经过通用校准和硬件适应程序后，冻结的系统在30次物理试验中全部成功。

为什么重要：显著减少了机器人技能开发中的人工投入，实现了具身智能体的自主自我改进。在模拟和现实世界中，展示了跨多样化操作任务的高可靠性和泛化能力。

局限：框架的初始能力识别依赖于离线数据集。尽管核心改进是自主的，但物理部署仍需“通用校准和硬件适应程序”，表明仍需一定程度的人工干预。

ScholarCatalyst: A Benchmark for Retrieving Papers That Inspire New Research

研究问题：尽管AI系统在解决开放性问题上取得进展，但在感知哪些现有想法对新问题至关重要方面，科学家仍远超AI。现有评估未能直接衡量这种“启发式检索”能力。

方法：构建ScholarCatalyst基准，用于检索能启发新研究的论文。通过自动化流程，让207篇计算机科学论文的184位主要作者标注哪些候选论文曾或可能推动了他们的项目，并提供详细理由。定义了一个检索任务：给定一个初始研究问题，从项目开始时可用的文献中检索这些论文。

结果：代理搜索的表现不优于嵌入检索（Recall@20分别为0.42 vs 0.48）。即使是可能在训练期间见过已完成论文的Claude Fable 5.1，也仅达到0.51 R@20。

为什么重要：揭示了AI在科学推理能力上的关键差距，并提供了一个独特的、由作者标注的基准，用于训练和评估AI系统识别启发性前期工作的能力，推动AI向具备“专家直觉”的科学代理发展。

局限：当前模型表现不佳，凸显了任务的难度。基准特定于计算机科学论文。

SILSA: Sliding-Window Slice Latents for Topology-Preserving High-Resolution 3D Generation

研究问题：高分辨率3D生成越来越依赖体素潜在表示和多阶段管道，但这种设计会导致连续表面碎片化、生成成本高昂，并常削弱薄或高度连接形状的拓扑一致性。

方法：引入SILSA，一个拓扑感知的3D生成框架，使用紧凑的滑动窗口切片潜在表示。通过沿三个规范轴的固定重叠切片集表示形状，每个切片总结局部深度窗口以保持横截面连续性并支持单阶段整流流生成。Slice VAE将定向表面样本编码为多轴切片潜在表示，并使用稀疏体素解码器重建。Volumetric Anchor Lattice通过共享3D工作空间协调定向切片流。引入切片级拓扑监督，匹配持久图并对齐相邻切片之间的Betti转换。

结果：在提高结构保真度的同时显著降低了生成成本。PSNR提高了8.7%，覆盖率提高了5.96个绝对点，Betti误差降低了9.2%，同时使用的token比次紧凑基线少70.0%，比稀疏或分层token化器少98%以上，有效减少了40.4%的训练内存和58.5%的推理时间。定性结果显示薄结构、重复组件和长距离连接的保留得到了改善。

为什么重要：提供了一种更高效、拓扑更一致的高分辨率3D生成方法，解决了现有基于体素方法的主要局限性。

局限：滑动窗口切片潜在表示对于某些极端复杂或非轴对齐的拓扑结构可能存在固有限制，尽管论文声称改进了保留效果。

VISTA: A Visual Harness for Reasoning in an Interactive World

研究问题：多模态模型具有强大的推理能力，但通常缺乏适当的“衔接器”来在多样化的交互环境中释放其解决长周期任务的潜力。

方法：引入VISTA，一个视觉衔接器，为通用多模态模型提供长周期视觉能力。它允许模型通过视觉观察直接感知环境，并维护无损的视觉记忆，以原始形式保留过去的观察。模型可以在推理时主动检索这些观察并重组其视觉输入。

结果：在ARC-AGI-3上，VISTA将Claude Opus 5.0的相对人类行动效率分数从40.68提高到完美的100.00，模型完成所有25个公共游戏所需的行动比首次人类参与者少57.4%。VISTA的简单设计也使其能够以最小的适应性自然扩展到多样化的视觉环境，并在三个额外的视觉游戏和谜题基准测试中显著优于使用相同底层模型但衔接器最小的基线。

为什么重要：证明了一个简单、通用的视觉衔接器可以显著增强多模态模型在复杂视觉环境中的推理和问题解决能力，推动更强大的多模态智能体发展。

局限：“简单设计”可能意味着它不是LLM本身的根本性架构改变，而是一种外部机制。性能仍与底层多模态模型的能力相关。

TACO: Ternary Absolute-max Column-wise One-sparse Optimizer for LLM Fine-Tuning

研究问题：大型语言模型（LLM）的全参数微调会产生大量的优化器状态内存开销，限制了可在现代GPU上微调的模型大小。

方法：提出TACO（Ternary Absolute-max Column-wise One-sparse Optimizer）。遵循Muon的算子范数最速下降视图，但在维度归一化的1→1算子范数下计算精确的最速下降方向。通过选择二维权重矩阵每列中最大幅值项的符号来保留一阶梯度。每列仅维护一小组低精度梯度分量。

结果：相对于AdamW8bit，在OPT-13B上将持久优化器状态减少了174倍（从27.7 GB到0.16 GB），峰值训练内存减少了2.9倍（从80.6 GB到27.5 GB），同时实现了可比的准确性和运行时性能。TACO进一步使得在单个80 GB H100 GPU上对30-32B参数模型进行全参数微调成为可能。

为什么重要：解决了LLM微调的关键内存瓶颈，使得在单个GPU上对更大模型进行全参数微调成为可能，从而普及了对高级LLM能力的访问。

局限：虽然实现了“可比的准确性和运行时性能”，但这可能不意味着在所有场景下都完全相同。1→1算子范数的特定几何结构可能对某些模型架构或任务产生影响，尽管论文声称具有广泛适用性。

InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation

研究问题：在不重新训练控制器的情况下解决新的人形机器人运动操作任务，需要重新利用现有技能、从尝试中改进并保留学习成果，这极具挑战性。

方法：引入InterEvolve，一个测试时进化框架。使用一个对象感知的正向-反向（FB）行为基础模型，将新的奖励转化为运动操作行为。任务被指定为奖励程序（具有完成条件和可调常量的分阶段奖励）。LLM代理根据执行反馈和技能库修改程序结构，同时数值优化器调整其常量。每个候选程序都在并行模拟场景中进行验证。

结果：人类设计的奖励未能充分利用FB模型的运动操作能力，而InterEvolve进化的程序则释放了这些能力，有时通过新颖的策略。它为模拟中的多样化任务、复杂场景和长周期组合生成了行为，并且进化的技能可以在物理Unitree G1机器人上通过自我中心机载感知自主运行。

为什么重要：使人形机器人能够在测试时适应新颖的运动操作任务，而无需昂贵的重新训练，通过智能地重新利用和组合现有技能。这是迈向更自主、更通用机器人的重要一步。

局限：依赖于现有的“广泛控制器”（FB行为基础模型）。LLM代理和数值优化器由模拟引导，尽管展示了物理试验，但模拟到现实的差距仍然是一个因素。
