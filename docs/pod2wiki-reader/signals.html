One Basis to Animate Them All: Gaussian Blendshape Distillation for Real-Time Avatars

研究问题：3D高斯头像的实时动画因昂贵的神经推理而面临挑战。

方法：引入GALA（Gaussian Animation via Linear Approximation），一种蒸馏方法，将预训练头像模型的动画近似为与身份无关的混合形状的线性组合。它用一个浅层系数预测器和线性混合来替代每帧繁重的神经解码。为提高保真度和减少内存，提出在渲染感知度量和内存预算下，使用块局部PCA构建基础。

结果：在三个不同的头像模型上验证了GALA，将CPU动画成本降低了高达三个数量级，同时保留了大部分渲染质量。该蒸馏方法泛化到未见过的身份，并在移动设备上实现了高达60fps的高效准确动画。

为什么重要：通过显著降低计算成本，GALA使3D高斯头像能够在移动设备上实现高效、准确的实时动画，证实了学习到的头像表示中存在共享的线性结构，极大地推动了实时虚拟形象技术的发展。

局限：该方法主要关注预训练模型的动画加速，可能未解决初始模型训练的成本问题，也未深入探讨其在生成全新、复杂动画风格方面的灵活性。

KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards

研究问题：大型语言模型（LLMs）在网络安全工作流中的应用日益增多，但现有评估侧重于知识或端到端代理任务，未能直接衡量LLMs生成可执行网络安全工具命令的能力，而这些命令对语法和参数绑定要求严格。

方法：引入KaliBench，一个针对Kali Linux上自然语言到CLI（命令行界面）转换的细粒度基准和数据集。包含8,504个查询-命令对，涵盖1,642个工具、23个能力维度和5个安全阶段。通过手稿驱动的管道构建，具有确定性规范化和别名感知评估。开发了多阶段验证管道，结合LLM验证、沙盒终端执行和人工精炼，以确保语义正确性和实际可执行性。还支持运行时无关的可验证奖励用于训练。

结果：在无限制设置下，没有开源模型在精确命令准确率上超过42%。通过KaliBench衍生的可验证奖励进行监督微调和强化学习，显著提升了8B模型的性能，使其与685B MoE模型相当。

为什么重要：KaliBench填补了LLM在网络安全领域评估的空白，为衡量和提升LLMs生成精确、可执行CLI命令的能力提供了关键工具和数据集。这对于将LLMs更有效地集成到实际网络安全操作中至关重要，并为训练更强大的网络安全代理提供了新途径。

局限：即使经过改进，开源模型在无限制设置下的精确命令准确率仍相对较低（42%），表明该任务难度大，仍有巨大提升空间。基准测试主要集中在Kali Linux工具上。

Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents

研究问题：在各种任务中构建可靠的机器人能力需要大量人工投入来开发和维护技能、设计奖励以及整合感知与控制。

方法：提出RPG（Reconstruct, Practice, Go Real），一个无需更新模型权重即可自主改进机器人执行系统的框架。RPG从离线数据集中识别操作能力，并在模拟中构建相关练习任务。在练习过程中，RPG利用执行反馈、特权模拟器状态和可用数据集视频来诊断故障。它根据诊断结果开发新的可重用符号技能，完善现有技能，并修改系统提示。跨任务评估测试单个候选更改和合并修订，然后将其保留以供重用。在测试时，多模态LLM使用生成的系统提示和技能库来协调感知和机器人控制。

结果：在22个操作任务的保留初始化上，RPG将任务成功率从第一轮练习后的28.6%提高到15轮后的95.0%，优于所有评估的基线（包括ASPIRE的75.5%和由GPT-6 Astra Pro驱动的CaP-Agent0的60.0%）。经过通用校准和硬件适应程序后，冻结的系统在30次物理试验中全部成功，其中三个任务各进行了十次试验。

为什么重要：RPG显著减少了机器人技能开发所需的人工投入，实现了具身智能体的自主自我改进。这使得机器人能够在多样化的操作任务中展现出高度可靠的能力，是迈向更自主、更通用机器人的重要一步。

局限：该框架依赖于离线数据集来识别初始操作能力。在物理试验中，仍需要“通用校准和硬件适应程序”，这可能意味着在实际部署前仍需一定程度的人工干预。

ScholarCatalyst: A Benchmark for Retrieving Papers That Inspire New Research

研究问题：尽管AI系统在解决开放性问题上取得进展，但在感知哪些现有想法（隐藏在不断增长的研究档案中）是新问题所需的方面，科学家仍远超AI系统。

方法：通过自动化流程构建ScholarCatalyst基准，该流程使作者标注具有可扩展性。184位207篇近期计算机科学论文的主要作者标注了哪些候选论文对他们的项目有或可能有帮助，并提供了详细理由。引入一个检索任务：给定一个初始研究问题，仅从项目开始时可用的文献中检索这些论文。

结果：代理搜索的表现不优于嵌入检索（Recall@20分别为0.42和0.48）。即使是基于Claude Fable 5.1构建的代理（可能在训练期间见过已完成的论文），也仅达到0.51的Recall@20。

为什么重要：ScholarCatalyst揭示了AI在进行专家级科学文献检索方面的显著不足，并提供了一个由作者标注的新型基准，以推动研究，使模型具备搜索广阔语料库的专家直觉，从而加速科学发现。

局限：当前模型在该基准上的表现不佳，凸显了任务的难度。该基准目前专注于计算机科学领域的论文。

SILSA: Sliding-Window Slice Latents for Topology-Preserving High-Resolution 3D Generation

研究问题：高分辨率3D生成日益依赖体素潜在表示和多阶段管道，但这种设计将连续表面碎片化为许多局部token，增加了生成成本，并常削弱薄或高度连接形状的拓扑一致性。

方法：引入SILSA，一个拓扑感知3D生成框架，用紧凑的滑动窗口切片潜在表示形状。SILSA不生成昂贵的体素token，而是使用沿三个规范轴的固定重叠切片集，每个token总结一个局部深度窗口以保持横截面连续性并支持单阶段整流流生成。Slice VAE将定向表面样本编码为多轴切片潜在表示，并用稀疏体素解码器重建。Volumetric Anchor Lattice通过共享3D工作空间协调定向切片流。为保持结构正确性，引入切片级拓扑监督，匹配持久图并对齐相邻切片之间的Betti转换。

结果：SILSA在结构保真度上有所提升，同时大幅降低了生成成本。PSNR提高了8.7%，覆盖率提高了5.96个绝对点，Betti误差降低了9.2%，同时使用的token比次紧凑的基线少70.0%，比稀疏或分层token化器少98%以上，有效减少了训练内存40.4%和推理时间58.5%。定性结果进一步显示薄结构、重复组件和长程连接的保留有所改善。

为什么重要：SILSA提供了一种更高效、拓扑更一致的高分辨率3D生成方法，显著降低了计算成本和内存需求，同时提高了结构保真度。这对于需要精确和复杂3D模型生成的应用（如虚拟现实、游戏开发和工业设计）具有重要意义。

局限：尽管在拓扑一致性方面有所改进，但对于极其复杂或精细的3D形状，生成质量和拓扑保持仍可能面临挑战。

VISTA: A Visual Harness for Reasoning in an Interactive World

研究问题：多模态模型具有强大的推理能力，但缺乏合适的“工具”（harness）来释放其在多样化交互环境中的潜力，尤其是在需要长期视觉记忆的任务中。

方法：引入VISTA，一个视觉工具，为通用多模态模型提供长程视觉。VISTA允许模型通过视觉观察直接感知环境，并维护无损的视觉记忆，以原始形式保留过去的观察。模型可以主动检索这些观察，并在推理时重新组织其视觉输入。

结果：在ARC-AGI-3上，VISTA将Claude Opus 5.0的相对人类行动效率分数从40.68提高到完美的100.00，模型完成了所有25个公共游戏，使用的行动比首次人类参与者少57.4%。VISTA的简单设计也使其能够以最小的适应性自然扩展到多样化的视觉环境。在涵盖各种视觉游戏和谜题的三个额外基准测试中，它显著优于使用相同底层模型但最小化工具的基线。

为什么重要：VISTA证明了一个通用视觉工具可以显著增强多模态模型在复杂交互视觉环境中的推理和性能，推动了更具能力的具身智能体的发展，使其能够更好地理解和操作视觉世界。

局限：VISTA的“简单设计”可能意味着它主要通过提供更好的信息访问来提升性能，而非从根本上改变底层模型的推理能力。其性能仍受限于所使用的多模态模型本身的局限性。

TACO: Ternary Absolute-max Column-wise One-sparse Optimizer for LLM Fine-Tuning

研究问题：大型语言模型（LLMs）的全参数微调会产生大量的优化器状态内存开销，限制了模型在现代GPU上可容纳的大小。现有方法通常会压缩优化器状态、放弃一阶梯度或改变更新几何结构，但仍保留密集状态。

方法：提出TACO（Ternary Absolute-max Column-wise One-sparse Optimizer），它遵循Muon的算子范数最速下降视图，但进一步采取几何路径。TACO通过选择二维权重矩阵每列中最大幅值项的符号，计算维度归一化1→1算子范数下的精确最速下降方向。这保留了一阶梯度，同时使优化器状态内存几乎可以忽略不计。

结果：相对于AdamW8bit，TACO将OPT-13B上的持久优化器状态减少了174倍（从27.7 GB降至0.16 GB），峰值训练内存减少了2.9倍（从80.6 GB降至27.5 GB），同时实现了可比的准确性和运行时性能。TACO还使得在单个80 GB H100 GPU上对30-32B参数模型进行全参数微调成为可能，适用于多个模型家族和任务。

为什么重要：TACO解决了LLM微调中的关键内存瓶颈，使得在更易获得的硬件上微调更大规模的模型成为可能，而无需牺牲性能。这极大地降低了LLM研究和部署的门槛，促进了先进LLM能力的普及。

局限：该方法旨在实现与现有优化器（如AdamW8bit）“可比的准确性和运行时性能”，而非显著超越。其主要优势在于内存效率，而非性能的绝对提升。

InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation

研究问题：人形机器人运动操作任务的解决通常需要对控制器进行重新训练或大量人工投入，即使控制器已具备相关基础技能。

方法：InterEvolve研究了人形机器人运动操作的测试时演化：通过重新利用现有技能、从自身尝试中改进并保留所学知识来解决控制器从未训练过的任务，而无需重新训练。其核心在于一个对象感知的正向-反向（FB）行为基础模型，它将关于身体或对象的新奖励转化为测试时的运动操作行为。任务被指定为奖励程序：具有完成条件和可调常量的分阶段奖励。一个大型语言模型（LLM）代理根据执行反馈和经验证的程序技能库，在上下文中修改程序结构，而数值优化器则调整其常量。每个候选程序都在并行模拟场景中进行验证，从而探索新的方式来诱导、重新利用和组合控制器的现有运动能力，并通过迭代进行改进。

结果：实验表明，人类设计的奖励未能充分利用FB模型的运动操作能力，而InterEvolve演化出的程序则释放了这些能力，有时甚至通过新颖的策略。它为模拟中的多样化任务、复杂场景和长程组合生成了行为，并且演化出的技能可以在物理Unitree G1机器人上通过自我中心机载感知自主运行。

为什么重要：InterEvolve使人形机器人能够在测试时适应新的运动操作任务，通过自主学习和技能重用，显著减少了对大量重新训练和人工干预的需求，从而推动了更通用、更自主的机器人发展。

局限：该方法依赖于一个预先存在的“广泛控制器”（FB行为基础模型）。LLM代理和数值优化器的迭代过程虽然自动化，但仍可能需要一定的计算资源和时间。
