CritICL: Inference-Time Weak-to-Strong Generalization from Small Language Model Failure Modes

研究问题：现有推理时LLM性能提升方法（如重复生成或外部验证）效率低下。

方法：提出CritICL框架，利用弱模型失败模式作为指导，通过基于批判的上下文示例进行推理。包括CritICL-dynamic（自适应预测失败模式）和CritICL-static（使用全局失败模式）。

结果：CritICL始终优于标准上下文学习，与测试时扩展方法性能相当或更优，且生成次数和token成本显著降低。

为什么重要：提供了一种高效的推理时LLM性能提升方法，无需重复生成或外部验证，降低了成本，同时保持了高推理性能。

局限：论文未明确列出，但该方法可能受限于弱模型失败模式识别的质量，以及批判性上下文示例构建的复杂性。

WikiSkill: Compiling Agent Experience into Persistent Knowledge for Skill Evolution

研究问题：AI Agent技能开发中，经验分散，难以系统重用和迭代，限制了Agent的适应性。

方法：提出WikiSkill框架，将原始执行经验、积累知识和可执行技能分离，持续将经验整合到持久知识库（wiki）中，供后续技能更新使用。

结果：WikiSkill在多个基准测试中始终优于现有技能演化方法；技能演化与模型规模互补（大模型受益更多，小模型带技能可胜过大模型无技能）；演化技能可跨模型和模型家族有效迁移。

为什么重要：提出一种系统化积累和提炼Agent经验的方法，促进可重用和可迁移技能的开发，显著提升Agent的适应性和性能，并揭示了技能演化与模型规模的互补性。

局限：论文未明确列出，但知识库的维护成本、经验整合的质量控制以及在极端复杂任务中的泛化能力可能需要进一步研究。

SWE-Prime: Fewer Trajectories, Better Performance

研究问题：现有LLM解决软件问题的方法依赖大规模Agent轨迹数据集进行SFT，但成功轨迹可能包含低效、冗余或有风险的步骤，引入噪声监督。

方法：提出SWE-Prime，一种多粒度两阶段SFT数据选择方法。第一阶段：轨迹级别筛选，基于过程质量、结果质量和数据代表性。第二阶段：片段级别选择，评估每个语义片段对解决方案的贡献、可学习性和潜在风险，仅选择的片段参与损失计算。

结果：仅使用SWE-Prime选择的10%轨迹子集进行训练，在SWE-Bench Pro和SWE-Bench Verified上性能优于使用完整数据集训练，相对性能提升高达12.2%和24.2%。

为什么重要：显著提升LLM解决真实世界软件问题的能力，通过高质量数据选择避免噪声监督，提高了训练效率和模型行为质量，为Agent轨迹数据的优化提供了有效途径。

局限：论文未明确列出，但筛选标准的设计可能存在主观性，且对特定类型错误或罕见场景的敏感性仍需深入评估。

TTPO: Test-Time Policy Optimization

研究问题：RL和OPSD等LLM后训练方法依赖真实标签，无法进行测试时训练（TTT）；多数投票伪标签易受错误投票影响，导致教师模型被腐蚀。

方法：提出TTPO（Test-Time Policy Optimization），一种非对称目标函数。通过OPSD蒸馏一致的rollout，通过Grouped RL惩罚不一致的rollout。令牌级选择进一步优化两个分支。

结果：在无标签情况下，TTPO在五个竞赛级基准测试中与标签监督的OPSD性能相当，将Qwen3-1.7B在TTT中从38.0%提升至45.2%，在无思考情况下提升25.2%至36.4%，并显示出强大的跨任务泛化能力。

为什么重要：提出一种无需真实标签的测试时策略优化方法，解决了现有方法对标签的依赖，提高了LLM在数学推理等任务上的泛化能力和鲁棒性，尤其在伪标签存在错误时仍能保持良好性能。

局限：论文未明确列出，但伪标签的质量仍是关键，尽管方法设计了鲁棒性，极端情况下的性能仍需考量，且其在非数学推理任务上的表现有待进一步验证。

From Static to Dynamic: Benchmarking Real-World Code Review with MCR-Bench

研究问题：现有LLM自动化代码审查方法将代码审查简化为单轮静态任务，未能捕捉真实世界多轮交互和复杂问题解决的本质。

方法：引入MCR-Bench，首个缺陷状态感知的多轮代码审查基准。包含2,269个真实世界多轮代码审查任务，覆盖五种编程语言，并标注细粒度缺陷信息和跨轮状态标签。

结果：主流LLM在缺陷检测和缺陷生命周期状态跟踪方面表现有限，随着交互轮次增加性能显著下降；性能因缺陷类型和严重程度而异；错误分析揭示了跨轮时间错位和长程记忆不足等关键弱点。

为什么重要：填补了真实世界多轮代码审查基准的空白，揭示了现有LLM在该任务上的局限性，为未来研究提供了更真实的评估工具和方向，有助于开发更符合实际场景的自动化代码审查系统。

局限：主流LLM在缺陷检测和缺陷生命周期状态跟踪方面表现有限，性能随交互轮次增加而显著下降；对语义复杂或低显著性缺陷的检测能力较弱；存在跨轮时间错位和长程记忆不足等问题。

RedEvoAgent: Automatic Red-Teaming Agent with Experience-Driven Skill Evolution

研究问题：现有LLM红队方法依赖固定攻击或轨迹检索，可能因检索偏差和工具归因不清而重用误导性经验，且完整轨迹增加上下文开销。

方法：提出RedEvoAgent，一种黑盒红队Agent。将跨案例攻击轨迹提炼成简洁、人类可读的攻击技能。通过工具有效性分析和决策工具归因来适应性演化攻击技能，并使用验证棘轮机制只保留能提升验证性能的更新。

结果：RedEvoAgent在多个基准、目标模型和执行环境中优于固定和Agent基线，提高了工具效率，并可在攻击者模型和目标执行环境之间迁移。

为什么重要：提高了LLM红队攻击的效率和有效性，通过技能演化克服了现有方法的局限性，增强了对LLM Agent安全风险的识别能力，对于部署在产品级执行环境中的Agent尤为重要。

局限：论文未明确列出，但黑盒攻击的局限性、技能提炼的准确性、以及验证棘轮的全面性可能需要进一步探讨，以确保其在面对新型或复杂漏洞时的有效性。

Stochastic Estimation of Transduced Language Models

研究问题：转换语言模型（TLM）中，计算目标前缀概率需要对源字符串进行求和，集合可能指数级大或无限，现有方法使用阈值剪枝束求和，产生误差未知的下界。

方法：提出一种无偏估计器。通过不重复重采样源前缀，并按其包含概率的倒数重新加权。递归应用此校正可得到目标前缀概率的无偏估计。束求和算法扩展保留的源前缀并采样要保留的前缀，随着更多概率质量的添加而减少前缀数量。

结果：在百科文本和DNA上，该方法比顺序蒙特卡洛基线具有更好的计算-方差权衡，在相同最大粒子数下DNA上误差更低。在DNA到氨基酸转换中，运行时比阈值剪枝束求和减少几个数量级，使长目标字符串的前缀概率估计可行。

为什么重要：解决了TLM中概率计算的效率和准确性问题，提供了一种无偏估计方法，显著提高了在复杂转换任务（如DNA序列分析）中的实用性，并能估计阈值剪枝造成的质量损失。

局限：论文未明确列出，但无偏估计器的方差控制、收敛速度以及在更复杂或高度歧义转换规则下的表现可能需要进一步研究。

Persona-Execution Separation: An Architecture Pattern for Evolving LLM Agents under Execution Audit

研究问题：受监管组织中的LLM Agent需要同时满足“人格”自由演化和“执行”可追溯审计的需求，单一信任域难以廉价实现。

方法：提出“人格-执行分离”（Persona-Execution Separation, PES）架构模式。人格和执行位于不同信任域，通过受治理的契约桥连接。人格可自由漂移，执行无面且可审计。通过审批矩阵、DLP和审计强制跨域。

结果：在受监管数字员工平台上的开发/试点案例中，记录了五项决策，并发现已实施的机制在人格扰动下没有执行侧的重新验证，硬断言字段上没有人格指纹。

为什么重要：为受监管组织中LLM Agent的设计提供了关键架构模式，解决了人格演化与执行可追溯性之间的冲突，确保了合规性和灵活性，避免了单一信任域带来的高昂耦合成本。

局限：在分离前的构建中，治理的执行路径与人格是因遗漏而解耦，而非通过构建实现；后来的布线更改可能逆转这种隔离，而PES将其作为审计的架构规则。
