Unbundling Multimodal Vision Encoding

研究问题：如何在多模态语言模型中有效编码视觉输入仍有争议，特别是关于视觉编码器的设计选择（预训练视觉先验、专用视觉容量、容量放置位置）。

方法：通过受控框架，从头开始在通用数据上预训练所有模型，并在匹配的计算量下，通过视觉问答和语言基准测试来解耦和比较不同的设计选择。

结果：视觉先验并非必需；从头联合训练的编码器与预训练编码器效果相当。专用视觉容量是关键；无编码器模型在视觉理解上表现不佳，即使增加骨干网络参数量也无济于事。但该容量不一定需要预先融合，在早期骨干层中添加的视觉专用模块与预融合编码器性能相当，并能缩短首个token生成时间。

为什么重要：为多模态语言模型中视觉编码器的设计提供了关键指导，表明从头开始联合训练专用视觉容量并将其放置在骨干网络早期层是高效且有效的策略，无需复杂的预训练阶段。

局限：论文未明确提及局限，但受控实验环境可能无法完全模拟所有真实世界复杂场景。

ArchSpace: Recording, Reviewing, and Referencing LLM Architecture Research

研究问题：LLM架构研究中，工业界缺乏成功或失败经验的公开文档，学术界受限于计算资源和不一致的基线，难以评估架构改进在大规模下的有效性。

方法：提出ArchSpace平台，用于记录、审查和引用架构研究。平台利用缩放定律从小型实验预测模型在大规模下的损失，以在昂贵的大规模训练前评估想法。提供Qwen3.5和OLMo3基线、拟合的缩放定律和可复用训练配方作为初始参考。

结果：ArchSpace旨在通过社区审查和引用，验证架构思想，并将其转化为新的基线，从而拓宽下一代模型的设计思路。

为什么重要：解决了LLM架构研究中信息共享和大规模验证的痛点，通过标准化平台和缩放定律，降低了架构创新的门槛和成本，加速了LLM架构的迭代和发展。

局限：平台的有效性依赖于社区的积极参与和审查质量；缩放定律的预测准确性在所有情况下可能存在局限。

ProtoVis-Nav: Prototypical Visual Imagination for Visual-Spatial Aligned UAV Navigation

研究问题：无人机（UAV）的视觉语言导航（VLN）面临挑战，因为3D运动预测中的微小误差可能导致导航错误和碰撞。现有方法难以从语言指令中预测准确的导航路径点。

方法：引入原型视觉想象框架（ProtoVis-Nav），强制模型为预期的下一个UAV运动想象一个与结果相关的局部视觉表示。通过预测特征原型并线性组合它们来估计目标区域的视觉特征。

结果：VLN模型首先想象下一个预期位置的局部视觉表示，然后使用预测的原型作为生成最终动作的上下文，从而促进视觉上下文和路径点输出之间的一致性。实验证明ProtoVis-Nav框架有效，并显著优于现有基线。

为什么重要：提高了无人机在复杂3D环境中的导航精度和鲁棒性，通过引入“视觉想象”机制，使模型能更好地理解语言指令并预测准确的3D运动，对自主导航系统有重要意义。

局限：论文未明确提及局限，但“原型视觉想象”的泛化能力和在极端复杂或未知环境中的表现可能需要进一步验证。

Internalizing Investment Mandates: A Neurosymbolic RL Approach to Portfolio Allocation

研究问题：深度强化学习在优化金融绩效方面表现出色，但通常无法强制执行投资政策声明中规定的资产配置约束，使其不适用于实际部署。现有神经符号方法（如PLPG）假设有限离散动作空间，不适用于连续分配。

方法：提出一种PLPG启发的连续分配方法，通过重参数化蒙特卡洛采样估计策略自身执行动作满足投资指令的概率，并将其添加到训练目标中。

结果：策略在推理时无需后验强制机制，通过学习内化了合规性。在没有修正的确定性平均动作上进行审计，该策略将违反六条制度条件指令的比例从无约束RL的96-98%和奖励惩罚基线的33.4%降低到4.8%。

为什么重要：解决了强化学习在金融领域实际应用中的关键障碍，使其能够遵守复杂的监管和投资政策，从而提高了金融AI系统的可信度和部署潜力。

局限：尽管显著降低了违规率，但仍有4.8%的违规，表明完全内化所有复杂规则仍有挑战。

AgentSSL: Can MLE Agents Leverage Unlabeled Data?

研究问题：机器学习工程（MLE）Agent主要在全监督设置下研究，但在标记数据稀缺而未标记数据丰富的现实场景中，其利用未标记数据的能力尚未得到充分测试。

方法：引入Agentic Semi-Supervised Learning (AgentSSL)，将半监督学习（SSL）框架为程序搜索问题，研究Agent在有限监督下如何探索该空间。引入ProgramSelectBench基准，包含16,977个Agent生成和人工设计的SSL程序，评估无监督和主动程序选择方法。

结果：Agent在弱反馈和匹配计算量下，能够合成结合和适应现有SSL技术的代码，在12种设置中的8种中超越最强的人工基线，最高提升21.8%。然而，程序选择是AgentSSL的关键瓶颈，基于Agent反馈指标选择时性能下降高达47%。

为什么重要：证明了MLE Agent在半监督学习场景下具有巨大潜力，能够自动化管道设计并超越人类工程基线，为解决数据稀缺问题提供了新途径。同时，也揭示了程序选择是当前AgentSSL面临的重要挑战。

局限：程序选择是关键瓶颈，性能受其影响显著；在真实世界生态检测任务上的泛化能力仍需进一步探索。

Learning When Diffusion Language Models Should Regenerate

研究问题：扩散语言模型（DLM）通过重掩码（remasking）可以修改生成的文本，但有效纠正需要知道何时以及如何修改。现有方法在错误信息暴露和孤立错误重现方面存在不足。

方法：诊断发现DLM的隐藏状态包含错误信息，但token置信度无法可靠暴露；固定上下文下重掩码孤立错误通常会重现。基于此，提出DiVR验证器，预测部分生成序列是否能达到正确答案。DiVR在模型自身轨迹的最终正确性上训练，决定何时重新生成块以及保留哪个替代方案，而生成器本身保持不变。

结果：在五个推理基准测试中，使用LLaDA-8B-Base，DiVR将微调生成器的平均准确率从35.3%提高到43.4%，成本是贪婪解码的1.9-3.5倍，优于使用3.8-7.4倍成本的搜索基线。它还能补充监督微调和强化学习等后训练方法，并泛化到其他生成器。

为什么重要：显著提升了扩散语言模型在推理任务中的准确性，通过智能地决定何时以及如何进行文本重生成，提高了模型的纠错能力和效率，对需要高精度推理的语言生成任务具有重要意义。

局限：成本仍高于贪婪解码；虽然优于搜索基线，但仍需权衡准确率提升与计算成本。

CoReMem: Cost-Internalizing Memory for Successive Coding Tasks with Prospective Valuation

研究问题：编码Agent在处理连续任务时，需要在任务未知的情况下，平衡未来记忆的有用性与写入和读取记忆的成本。Agent还需要决定何时利用现有记忆来节省工作量。

方法：引入CoReMem（Coding-Repository Memory），一个成本内化框架，通过衡量记忆在下一个任务上的价值来指导记忆设计和Agent适应。前瞻性片段估值比较有无记忆的下一个任务运行，指导围绕锚点（仓库位置和可执行检查）构建紧凑记忆。Agent适应通过在有无记忆的回合组中估计策略内记忆价值，使用优先解决问题并惩罚成功运行中步骤数的奖励。

结果：在ChainSWE基准测试中，CoReMem将27B Agent的解决率从21.0%提高到25.7%，同时减少了17%的步骤和11%的总缓存感知token（包括记忆模块调用），相对于未经训练的无记忆Agent模型。

为什么重要：提高了编码Agent在连续编程任务中的效率和解决率，通过智能的记忆管理和成本内化机制，使Agent能够更有效地利用历史信息，减少重复工作和计算资源消耗。

局限：评估主要在ChainSWE基准上进行，泛化到更广泛的编程任务和环境可能需要进一步验证。

Sketching Language Models for Context Attribution

研究问题：上下文归因（Context attribution）旨在量化移除提示词部分如何影响语言模型输出。直接计算所有“留一法”（LOO）值需要N次模型评估，成本高昂。

方法：提出一种基于速写（sketching）的算法，在稳定性假设下，以常数概率在$O(\sqrt{\log(1/\varepsilon)}/\varepsilon)$次评估调用内估计所有LOO值，误差与$\varepsilon$成比例。技术上，该方法将前向微分应用于反向传播电路，以降低速写方差。

结果：算法在理论上达到了匹配的$Ω(\sqrt{\log(1/\varepsilon)}/\varepsilon)$评估调用次数下限。经验上，在小型语言模型检索任务中验证了稳定性系数衰减和算法性能。

为什么重要：大幅降低了语言模型上下文归因的计算成本，使其在实际应用中更可行。这有助于理解模型决策过程，提高模型的可解释性和可信度。

局限：依赖于稳定性假设；经验验证是在小型语言模型检索任务上进行的，在大规模复杂任务上的表现仍需进一步验证。
