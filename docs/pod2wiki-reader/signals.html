PlayCraft: Designing Engaging Games from Agent Play Experience

研究问题：现有AI代理能生成可玩游戏，但这些游戏缺乏吸引力，特别是难以通过设计实现精通感（mastery），而精通感是游戏吸引力的关键来源。设计精通感通常需要大量人类玩家测试和调整。

方法：提出PlayCraft框架，一个自动化系统，利用基于视觉的代理通过重复游戏体验来修订游戏，以增强精通感。该框架交替进行“玩”和“制作”：玩家代理观察屏幕、操作控制并追求游戏目标，同时保留记忆并报告进度、结果、决策和反思；制作代理利用这些报告评估玩家能力、预测不同熟练度下的表现，并根据目标学习进程诊断游戏，通过提供有意义的改进机会来修订游戏。

结果：与初始游戏相比，PlayCraft在大多数游戏中产生了更大的学习增益和更陡峭的学习曲线。在每个智能设置下，它在各项指标的宏观平均表现上均优于基线方法。

为什么重要：该框架提供了一种自动化设计引人入胜游戏的方法，通过专注于精通感来减少对大量人工测试和调整的依赖，有望提升AI生成游戏的质量和玩家体验。

局限：论文主要关注“精通感”这一吸引力来源，可能未涵盖其他重要的游戏吸引力因素。评估是基于玩家代理而非人类玩家，其体验与人类玩家可能存在差异。

TideCache: Efficient Hybrid LLM Serving with Transparent Cache Management and Layer-Wise Streaming

研究问题：混合架构已成为开源大型语言模型（LLM）的主流，其全局注意力层和有界状态层维护着异构缓存，这些缓存的需求随上下文长度和并发性而变化，导致在CPU-GPU超芯片上高效分配和管理GPU内存面临挑战。

方法：提出TideCache服务系统，包含三个组件用于在缓存之间分配GPU内存并在GPU和主机内存之间管理其驻留：1) 透明缓存池，在固定虚拟地址后重新分配物理页面，保持缓存布局和后端接口；2) 缓存流媒体，利用有界状态层提供的计算间隔，将下一个全局注意力层的前缀预取到全局注意力层共享的GPU槽中，减少GPU驻留并与计算重叠；3) 请求调度器，根据请求大小和队列状态选择驻留或流式执行，并触发容量调整。

结果：在SGLang中实现，并在GB300和GH200上针对七种模型/平台配置进行评估。TideCache完成的代理回合数最多可达2.04倍，将整体P50每token延迟降低20-59%，并将代理P50 TTFT（首次token生成时间）提高1.40-3.05倍，优于使用HiCache的SGLang。

为什么重要：显著提高了混合LLM在超芯片架构上的服务效率和延迟，使得LLM能够处理更多请求并提供更快的响应，对于大规模部署和应用至关重要。

局限：评估主要基于SGLang框架和特定的GB300、GH200硬件平台，其在其他LLM服务框架或不同硬件配置上的通用性可能需要进一步验证。

AgentRoboCritic: Understanding the Capability of Frontier Agents on Direct Robot Control

研究问题：前沿多模态语言代理（如GPT-6 Astra）在通过低级数值动作直接控制机器人方面表现出强大能力，但现有基准测试仅报告回合级成功率，未能揭示这些代理如何成功或在何处失败，缺乏动作级别的细致分析。

方法：提出AgentRoboCritic，一个意图导向的批判框架，用于对12个操作基准上的前沿代理进行系统性的动作级别分析。在该框架中，策略代理在每个动作的同时声明一个局部意图，批判器根据该意图评估动作的结果和失败模式。论文还验证了批判器在一个包含400个动作的人工标注基准上，并发布了一个包含12,844个标注动作的数据集，以及一个经过微调的开源批判器Muse-Glimmer-30B。

结果：动作级别分析展示了前沿代理在直接机器人控制方面的潜力，包括从局部执行失败中闭环恢复、跨多样场景的可靠语义接地以及强大的零样本操作能力。同时也识别出其局限性，包括抓取和对齐等与任务相关的物理执行瓶颈，以及在不同失败模式下恢复能力不均。微调后的Muse-Glimmer-30B批判器的失败模式准确率从32.58%提高到74.24%。

为什么重要：提供了一个系统性的动作级别分析框架，深入理解前沿AI代理在机器人控制中的能力和局限性，有助于更精准地改进机器人策略和代理设计，推动机器人技术发展。

局限：论文识别出的局限性（如物理执行瓶颈）是针对所研究的代理本身，而非批判框架的局限。批判器的准确率虽有提升，但仍有改进空间。

SoK: Assessing the Evolution of LLM Capability in Software Vulnerability Research

研究问题：关于LLM代理在软件漏洞研究中能力的说法分散在论文、供应商报告和披露中，且难以比较，导致难以系统评估其演变和影响。

方法：引入一个框架，根据类似于驾驶自动化级别的自主性等级来评估LLM的能力，并通过正确性、可用性和证据强度来限定每个主张。使用此框架系统化了LLM在漏洞研究中能力的已发表证据，并测量了LLM安全能力演变在十年公共漏洞记录、咨询和利用数据中的后果。

结果：发现LLM代理在2026年受限前沿模型出现之前，就已经在没有人为干预的情况下发现、验证和修补了真实软件中的漏洞，并且开源模型随后在发现和验证方面达到了可比的自主性。2026年，披露的漏洞数量增加了一倍多，其中严重或高危漏洞的比例增加，并且在广泛使用的代码中存在十年或更长时间的严重错误被报告的频率是以前的数倍。然而，漏洞生命周期各阶段（从报告到修复，从披露到攻击）之间的时间尚未发生显著变化。

为什么重要：首次系统性地评估了LLM在软件漏洞研究中的能力演变及其对行业的影响，揭示了LLM在漏洞发现方面的巨大潜力，并为利益相关者提供了缓解措施的指导。

局限：尽管LLM显著增加了漏洞披露数量和严重性，但从报告到修复、从披露到攻击的时间并未明显缩短，这表明LLM可能更多地是发现漏洞，而非加速整个漏洞生命周期。该框架依赖于已发表证据，可能存在选择性偏差。

A Tutorial on Complementarity-Based Contact Models for Robotics

研究问题：模拟刚体接触动力学是机器人学的基础，但广泛使用的锥互补公式的物理假设和数值解需要深厚的背景知识。现有综述、专著或课程笔记主要面向计算力学或计算机图形学，或仅记录单一模拟器，缺乏为机器人学提供统一符号、完整推导和自洽教学的资源。

方法：本教程旨在弥补这一空白，将刚体动力学、锥优化和摩擦接触结合起来。具体解释了互补条件如何编码非穿透和摩擦耗散，区分了等效转录和凸松弛，探讨了运动和接触力的存在性和唯一性，并比较了不同求解器方法（一阶和基于牛顿的方法、正则化和近端策略），讨论了计算成本、鲁棒性和物理保真度之间的权衡。

结果：提供了一个自洽的教学资源，统一了锥互补接触模型的符号和推导。解释了物理假设、数值解、凸松弛可能引入的伪影，以及求解器在多解选择中的作用。帮助读者理解模拟结果，选择合适的公式和求解器，并开发自己的接触动力学例程。

为什么重要：填补了机器人学领域在接触模型教学方面的空白，为机器人研究人员和实践者提供了理解、应用和开发接触动力学算法的全面指导，有助于提升机器人模拟的准确性和效率。

局限：作为一篇教程，其主要成果在于知识的整合和清晰的解释，而非提出新的科学发现。其有效性取决于读者的背景知识和学习投入。

Active Feature Acquisition by Distilling an Oracle Teacher

研究问题：获取实例的每个特征通常成本高昂（金钱、时间或隐私）。主动特征获取（AFA）旨在学习一种策略，在预算内决定为每个实例获取哪些特征。然而，现有AFA方法通过优化自构建的效用目标来训练策略，而非显式地蒸馏一个教师模型。

方法：提出OracleImitator，它显式构建了一个教师模型。在训练时，标签和未观测特征值可用，它们共同以闭合形式确定教师模型：一个根据对下游预测器误差的影响来对每个候选特征进行排名的预言机。OracleImitator通过软目标模仿将这个排名蒸馏成一个可部署的策略。

结果：在多模态医学诊断和AFABench基准测试中，OracleImitator在整个预算范围内匹配或超越了现有AFA方法，以不到四分之一的获取成本恢复了90%可达到的准确率增益。由于教师模型是一个显式的算法对象而非隐式优化目标，因此可以直接衡量其排名有多少可被部署时可见的策略恢复。

为什么重要：通过引入显式预言机教师模型，显著提高了主动特征获取的效率和准确性，在保持性能的同时大幅降低了特征获取成本，对实际应用具有重要价值。

局限：预言机教师模型在训练时可以访问所有信息，但在部署时策略受限于可见信息，因此无法完全恢复预言机的所有排名信息。

PGX: Physically Grounded Execution for Long-Horizon Humanoid Loco-Manipulation

研究问题：机器人视觉-语言-动作（VLA）模型可以执行多样化的个体操作技能，但由于时间结构、技能和精度在单一模型中紧密耦合，它们在长周期（long-horizon）的运动-操作（loco-manipulation）任务中仍然面临挑战。

方法：提出物理接地执行（PGX）框架，将时间结构和精度控制卸载到两个经典的、无需训练的组件，使VLA模型能够专注于特定阶段的技能动力学。PGX将长周期运动-操作分解为三层：1) 基于谓词的状态机，管理任务进程，使用物理谓词来控制阶段转换、触发恢复并协调导航和等待；2) VLA技能，在主动操作阶段运行，平坦或阶段训练的模型专注于任务相关动作；3) 世界坐标锁定（WCL），通过基础站位保持、物体相对定位和世界锚定接触目标来维持空间一致性。

结果：通过在三个模拟任务和一个使用Unitree G1人形机器人的真实世界任务中进行大量实验，证明了PGX在长周期运动-操作中的有效性，显示出阶段进展和任务成功率的提高。

为什么重要：通过解耦复杂任务中的时间与精度控制，显著提升了VLA模型处理长周期运动-操作任务的能力，为人形机器人实现更复杂、更鲁棒的行为提供了有效途径。

局限：实验主要在特定模拟任务和Unitree G1人形机器人上进行，其在更广泛、更复杂的机器人平台或非结构化环境中的通用性可能需要进一步验证。框架依赖于经典的无训练组件，这些组件本身可能存在局限性。

Realized versus Population Reliability: Anytime-Valid Self-Consistency Certification under Correlated Reasoning

研究问题：语言模型（LLM）的自洽性认证将重复采样视为顺序证据积累，并在随时有效e-过程超过阈值时停止，通过Ville不等式保证有限样本I型错误控制。然而，现有构造假设采样结果是条件独立的，这在实践中并不成立：推理流通过共享推理前缀或跨提示异质性而呈正相关，这不仅改变了证书效率，也改变了所认证的假设。

方法：通过每单元潜在状态（随机效应/组内相关结构）建模依赖性，诱导具有相关性ρ的可交换、等相关增量。将单一零假设分解为关于抽样信念的“已实现零假设”和关于平均模型行为的“总体零假设”，两者仅在ρ=0时重合。论文展示了：1) 标准投注e-过程对已实现零假设仍然随时有效，但对总体零假设无效；2) 作为总体零假设检验，合适的混合具有渐近交叉概率，可能超过名义ε；3) 单元内均值的有效样本量饱和在1/ρ，因此额外的单元内采样无法恢复总体有效性；4) 提示级e-过程恢复了总体有效性，在纯采样预算下，每个提示一次采样是最佳分配。

结果：模拟和Claude Haiku 4.5的采样结果证实了这种机制依赖性：在GSM8K上（ρ̂=0.435，θ̂=+0.96）差距不明显，而在AIME上（ρ̂=0.480，θ̂=-0.15），单单元规则在24%的提示上以名义ε=0.05交叉，而提示级过程则下降（0.00）。

为什么重要：澄清了在相关推理下自洽性认证的统计保证，明确了随时有效证书实际支持的可靠性主张，为LLM可靠性评估提供了更准确的理论基础和实践指导，尤其在需要总体推断时。

局限：研究揭示了现有方法在相关性存在时的局限性，并提出了提示级e-过程作为解决方案，但其在不同应用场景下的实际开销和适用性可能需要进一步评估。
