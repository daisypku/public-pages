One Basis to Animate Them All: Gaussian Blendshape Distillation for Real-Time Avatars

研究问题：3D高斯头像虽然渲染速度快，但其实时动画因昂贵的神经推理而面临挑战。

方法：引入GALA（Gaussian Animation via Linear Approximation），一种蒸馏方法。它通过身份无关的混合形状的线性组合来近似预训练头像模型的动画。该方法用一个浅层系数预测器和线性混合取代了每帧繁重的神经解码。为提高保真度和减少内存，GALA使用渲染感知度量和内存预算下的块局部PCA来构建基。它学习一个浅层MLP网络来预测混合形状系数，并适用于各种动画架构而无需重新训练原始模型。

结果：GALA成功加速了三种不同头像模型（面部表情、全身及服装动态）的推理。在这些模型中，蒸馏方法泛化到未见过的身份，并将CPU动画成本降低了高达三个数量级，同时保留了大部分渲染质量。在移动设备上实现了高达60fps的高效准确动画。

为什么重要：该方法使3D高斯头像的实时高效动画成为可能，极大地拓宽了其在移动设备和实时应用中的实用性，并证实了学习到的头像表示中存在共享的线性结构。

局限：蒸馏方法本质上涉及近似，论文中“保留了大部分渲染质量”暗示可能存在一定程度的质量损失。此外，该方法依赖于预训练的头像模型，其性能受限于原始模型的质量。

KaliBench: A Fine-Grained Benchmark for Cybersecurity Tool Use on Kali Linux with Runtime-Free Verifiable Rewards

研究问题：大型语言模型（LLMs）在网络安全工作流中的应用日益增多，但现有评估侧重于知识或端到端代理任务，未能直接衡量LLMs生成真实网络安全工具可执行命令的能力，而这些命令对CLI语法要求严格。

方法：引入KaliBench，一个针对Kali Linux上自然语言到CLI转换的细粒度基准和数据集。包含8,504个查询-命令对，涵盖23个能力维度和5个安全阶段的1,642个工具。通过手稿驱动的管道构建，具有确定性规范化和别名感知评估，以实现工具选择和参数构造的精确可重现评估。开发了一个多阶段验证管道（基于LLM的验证、沙盒终端执行和人工循环细化），以确保语义正确性和实际可执行性。KaliBench还支持用于训练的免运行时可验证奖励。

结果：在无限制设置下，没有开放权重模型在精确命令准确率上超过42%，突显了在没有明确工具提示下准确使用CLI网络安全工具的难度。通过KaliBench衍生的可验证奖励进行监督微调和强化学习，显著提升了一个8B模型，并实现了与685B MoE模型相当的性能。

为什么重要：KaliBench填补了LLMs在实际网络安全操作中生成可执行CLI命令评估的空白，为开发能够准确执行网络安全任务的LLMs提供了关键基准和数据集，对自动化网络安全工作流至关重要。

局限：即使经过微调，开放权重模型的精确命令准确率仍相对较低（42%），表明仍有很大的改进空间。该基准专注于Kali Linux工具，可能无法涵盖所有网络安全环境。

Reconstruct, Practice, Go Real: Guided Self-Improvement for Embodied Agents

研究问题：在多样化任务中构建可靠的机器人能力需要大量人工投入来开发和维护技能、设计奖励以及整合感知与控制。

方法：提出了RPG（Reconstruct, Practice, Go Real）框架，用于在不更新模型权重的情况下自主改进机器人执行系统。RPG从离线数据集中识别操作能力，并在模拟中构建相关的练习任务。在练习过程中，RPG利用执行反馈、特权模拟器状态和可用数据集视频来诊断故障。它根据诊断结果开发新的可重用符号技能，完善现有技能，并修改系统提示。跨任务评估用于测试单个候选更改和合并修订，然后将其保留以供重用。在测试时，多模态LLM使用生成的系统提示和技能库来协调感知和机器人控制。

结果：在22个操作任务的未见过初始化上，RPG在15轮练习后将任务成功率从28.6%提高到95.0%，优于所有评估的基线（包括ASPIRE的75.5%和由GPT-6 Astra Pro驱动的CaP-Agent0的60.0%）。经过通用校准和硬件适应程序后，冻结的系统在30次物理试验中全部成功，其中三个任务各进行了十次试验。

为什么重要：RPG提供了一种机器人自主改进复杂操作任务能力的新颖方法，显著减少了人工投入，并使具身智能体更具鲁棒性和适应性。其在不更新模型权重的情况下实现改进的特点，对于提高效率和部署灵活性具有重要意义。

局限：该方法依赖于离线数据集进行初始能力识别。改进主要发生在模拟环境中，需要进行“通用校准和硬件适应程序”才能在真实世界中部署，这可能仍涉及一定的人工投入或领域专业知识。任务的复杂性可能受限于初始技能库和LLM修改提示的能力。

ScholarCatalyst: A Benchmark for Retrieving Papers That Inspire New Research

研究问题：AI系统在识别能够启发新研究的现有思想方面表现不佳，而这是科学家擅长的技能。现有检索基准可能无法捕捉这种“专家直觉”。

方法：引入ScholarCatalyst，一个用于检索启发新研究论文的基准。利用自动化管道扩展作者标注：184位207篇近期计算机科学论文的主要作者标注了哪些候选论文已经或可能推动了他们的项目，并提供了详细理由。任务是给定一个初始研究问题，仅从项目开始时可用的文献中检索这些论文。

结果：代理搜索的表现不优于嵌入检索（Recall@20分别为0.42和0.48）。即使是基于Claude Fable 5.1构建的代理（可能在训练期间见过已完成的论文），R@20也仅达到0.51。这些结果突显了需要新的训练方法来使模型具备搜索广泛语料库的专家直觉。

为什么重要：该基准揭示了当前AI在进行“专家直觉”式研究检索方面的显著差距，为开发能够有效指导研究人员、识别真正相关和启发性前期工作的科学代理提供了宝贵工具。

局限：R@20分数相对较低，表明任务难度和当前模型的局限性。该基准特定于计算机科学论文。使用嵌入检索作为工具的“代理搜索”可能未能充分探索更复杂代理推理的潜力。

SILSA: Sliding-Window Slice Latents for Topology-Preserving High-Resolution 3D Generation

研究问题：高分辨率3D生成越来越依赖体素潜在表示和多阶段管道，这通常会分割连续表面、增加生成成本，并削弱薄或高度连接形状的拓扑一致性。

方法：引入SILSA，一个拓扑感知的3D生成框架。它使用紧凑的滑动窗口切片潜在表示形状，而不是昂贵的体素token。SILSA沿三个规范轴使用一组固定的重叠切片，每个token总结一个局部深度窗口，以保持横截面连续性并支持单阶段整流流生成。一个切片VAE将定向表面样本编码为多轴切片潜在表示，并使用稀疏体素解码器进行重建，而一个体素锚点格（Volumetric Anchor Lattice）通过共享的3D工作空间协调定向切片流。为保持结构正确性，引入了切片级拓扑监督，匹配持久图并对齐相邻切片之间的Betti转换。

结果：SILSA提高了结构保真度，同时大幅降低了生成成本。与最强基线相比，PSNR提高了8.7%，覆盖率提高了5.96个绝对点，Betti误差降低了9.2%。它使用的token数量比次紧凑的基线少70.0%，比稀疏或分层token化器少98%以上，有效将训练内存减少了40.4%，推理时间减少了58.5%。定性结果进一步显示了对薄结构、重复组件和长距离连接的更好保留。

为什么重要：SILSA提供了一种更高效、拓扑更鲁棒的高分辨率3D生成方法，解决了成本和结构完整性方面的关键挑战，有望在各种应用中生成更真实和可用的3D模型。

局限：尽管改进了拓扑结构，但该方法仍依赖于“切片级”监督，复杂的全局拓扑特征可能仍然具有挑战性。与多阶段方法相比，其“单阶段整流流生成”在某些场景下可能存在自身的权衡。

VISTA: A Visual Harness for Reasoning in an Interactive World

研究问题：多模态模型具有强大的推理能力，但需要一个合适的“衔接器”来释放其在多样化交互环境中解决长程任务的潜力，尤其是在视觉记忆和感知方面。

方法：引入VISTA，一个为通用多模态模型提供长程视觉的视觉衔接器。它允许模型通过视觉观察直接感知环境，并维护一个无损的视觉记忆，以原始形式保留过去的观察。模型可以主动检索这些观察并重新组织其视觉输入以进行推理。

结果：在ARC-AGI-3上，VISTA将Claude Opus 5.0的相对人类行动效率分数从40.68提高到完美的100.00，模型完成了所有25个公共游戏，使用的行动比首次人类参与者少57.4%。VISTA的简单设计也使其能够以最小的适应性自然扩展到多样化的视觉环境。在涵盖各种视觉游戏和谜题的三个额外基准测试中，它显著优于使用相同底层模型但衔接器最小的基线。

为什么重要：VISTA展示了一种简单而有效的方法，通过提供强大的视觉记忆和感知能力，显著增强多模态模型在复杂视觉环境中的推理和性能，是迈向更强大、更通用多模态代理的重要一步。

局限：“简单设计”可能意味着它是一个通用框架，但对于高度专业化的视觉环境，可能仍需要特定的适应。论文主要关注视觉游戏和谜题；真实世界的开放式视觉任务可能带来新的挑战。

TACO: Ternary Absolute-max Column-wise One-sparse Optimizer for LLM Fine-Tuning

研究问题：大型语言模型（LLMs）的全参数微调会产生大量的优化器状态内存开销，限制了模型在现代GPU上可容纳的大小。

方法：提出了TACO（Ternary Absolute-max Column-wise One-sparse Optimizer），一种遵循Muon算子范数最速下降视图但进一步采取几何路径的优化器。TACO通过选择二维权重矩阵每列中最大幅值项的符号，计算维度归一化1→1算子范数下的精确最速下降方向。这保留了一阶梯度，同时使优化器状态内存几乎可以忽略不计。它每列仅维护一小部分低精度梯度分量。

结果：在OPT-13B模型上，TACO将持久优化器状态相对于AdamW8bit减少了174倍（从27.7 GB降至0.16 GB），并将峰值训练内存减少了2.9倍（从80.6 GB降至27.5 GB）。它实现了可比的准确性和运行时性能。TACO进一步使得在单个80 GB H100 GPU上对30-32B参数模型进行全参数微调成为可能，适用于多个模型家族和任务。

为什么重要：TACO显著降低了LLM微调的内存需求，使得更大的模型可以在单个GPU上进行微调，从而普及了对高级LLM能力的访问，并加速了研究和开发。

局限：尽管实现了“可比的准确性”，但在非常特定的场景下，其性能或收敛行为可能与AdamW存在细微差异。该方法的有效性已在特定模型家族和任务上得到验证；更广泛的泛化可能需要进一步验证。

InterEvolve: Test-Time Evolution of Reward Programs for Humanoid Loco-Manipulation

研究问题：人形机器人运动操作任务通常要求控制器解决未经明确训练的任务，需要在不完全重新训练的情况下进行适应。现有方法可能不足以表达复杂、接触丰富的交互，或缺乏有效的反馈引导规划。

方法：引入InterEvolve，用于人形机器人运动操作的测试时奖励程序进化。它使用一个对象感知的正向-反向（FB）行为基础模型（冻结的身体先验，对象残差）将新奖励转化为运动操作行为。任务被指定为奖励程序（具有完成条件和可调常量的分阶段奖励）。一个大型语言模型（LLM）代理根据执行反馈和技能库修改程序结构，而数值优化器调整其常量。候选程序在并行模拟场景中进行验证。

结果：人工设计的奖励未能充分利用FB模型的运动操作能力；InterEvolve进化的程序释放了这些能力，有时通过新颖的策略。它在模拟中为多样化任务、复杂场景和长程组合生成了行为。进化的技能可以在物理Unitree G1机器人上通过自我中心机载感知自主运行。

为什么重要：InterEvolve使人形机器人能够在测试时通过智能进化奖励程序来适应和解决新的复杂运动操作任务，而无需重新训练。这显著增强了机器人在动态环境中的自主性和多功能性。

局限：该方法依赖于现有的“通用控制器”（FB行为基础模型）作为基础。LLM代理修改程序的能力至关重要，对于高度新颖的任务可能成为瓶颈。并行模拟中的验证虽然高效，但仍存在模拟到现实的差距问题，影响物理部署。
