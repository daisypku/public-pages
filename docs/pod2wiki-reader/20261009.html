E255｜模型越来越强，为什么用户没感觉？再访阿里国际站总裁张阔

本期节目深入探讨了当前大模型技术在通用能力与实际应用之间存在的巨大鸿沟。尽管AI模型在各项通用测试中表现出色，但其在真实商业场景，特别是像跨境电商这样复杂、长周期、非结构化数据多的领域，仍面临巨大挑战。核心观点是，Agent（AI智能体）要真正发挥作用，需要将通用大模型与特定业务场景的“工具集（harness）”和“上下文（context）”深度结合，才能从理论上的高分转化为实际的生产力提升。这期节目适合关注AI技术落地、商业智能化转型，以及对Agent产品发展趋势感兴趣的听众。

  • 通用AI模型与实际业务需求的鸿沟：主持人伊文指出，尽管大模型在各类榜单上成绩斐然，但用户在实际工作中并未感受到同等幅度的效率提升。张阔对此深有同感，他分享阿里国际站团队的经验：通用模型评测接近满分，但在真实业务中，AI在无人干预下完成107个特定任务的成功率远低于预期。他将AI应用分为两类：编程类（coding）和工作类（work）。编程任务因其100%代码化、数据易于学习、结果可立即验证等特点，AI渗透率已达99%。而商业工作则复杂得多，数据多元、流程非标准化、结果验证周期长且判断标准因企业目标而异，使得通用AI难以直接发挥效用。这揭示了AI从实验室走向实际应用时，需要解决的深层问题。
  • Axel Work的演进：从AI搜索到AI驱动的交易：张阔介绍了阿里国际站的Agent产品Axel Work的演进。最初，Axel Work主要解决AI搜索问题，作为Alibaba.com的AI模式，允许买家通过自然语言或多模态方式描述需求，使得多模态搜索增长了130%。第二阶段，Agent能力扩展到采购（sourcing）前后环节，包括市场调研、产品设计包（design pack）制作、与供应商沟通、乃至完成交易，形成“agentic trade”的完整路径。最新阶段，即今年4月推出的Axel Work，进一步泛化，旨在通过一站式服务管理用户在Amazon、Shopify、eBay、TikTok等多个电商平台的经营情况，包括店铺管理、社交内容生成、定价策略、买家反馈处理等，实现跨端生意管理。
  • 跨境商家案例：AI如何赋能产品从创意到全球销售：张阔以一个跨境商家Adword的案例，具体阐述了Axel Work如何赋能。该商家希望创造一款能感知植物状态的智能电子产品。从最初的创意到产品落地，传统方式需要耗费大量精力进行市场调研、产品设计、寻找工厂、成本控制、物流报关、多平台营销等。Axel Work能将这一复杂流程极大简化：它帮助商家设计出专业的design pack，匹配广东深圳的优秀电子产品制造商，处理船期、HS code报关、当地物流等跨境难题。产品制造完成后，AI还能协助生成符合各平台规则的社交内容，管理多店铺运营、定价和买家反馈。原本耗时数月的工作，通过AI可缩短至数天甚至24小时内完成，显著提升了创业者和商家的效率和成功率。
  • Agent成功的核心公式：Model x Harness x Context：张阔提出了一个Agent成功的核心公式：Agent = Model x Harness x Context。他强调这是乘法关系，任何一项为零，结果都为零。Model指底层大模型，Harness指连接各种工具、管理记忆、用户授权等工程体系，Context则指业务场景的上下文数据。中美市场在SaaS生态上存在差异：美国SaaS垂直化程度高，而中国平台整合功能更多。这导致AI在不同市场落地时，Harness和Context会有所不同。例如，Alibaba.com和1688积累的20多年电商数据、供应商交流、商业数据、行业趋势等，都是构建强大Context的关键。他指出，AI产品天生具有全球化潜力，语言障碍不再是问题，但不同区域的用户交互和工具集成仍需差异化处理。
  • SaaS公司与Agent的共生关系及竞争格局：对于Agent对SaaS公司的影响，张阔认为，如果SaaS业务内容简单，AI确实可能削弱其能力。但对于与工作流紧密结合、理解企业上下文和经营目标的SaaS公司，AI反而是利好。AI进入企业，也必须理解企业数据含义和老板的优化目标（例如追求利润还是市场份额），这些是通用AI无法直接完成的。因此，SaaS公司需围绕AI升级产品，而AI也需与SaaS结合，形成互相促进的共生关系。他观察到，当前Agent领域的竞争已是多元化、全方位的竞争，不再是简单地使用通用模型加Prompt就能解决问题。垂直领域的Agent之所以能脱颖而出，正是因为它们在Model、Harness和Context三个维度上进行了深度打磨和优化。

这期播客深入探讨了开放模型在AI安全、创新生态中的关键作用，以及构建前沿AI模型的巨大挑战与战略演变。它适合关注AI技术发展、产业格局、开放与封闭模型之争的投资者、研究者和技术爱好者。

  • 开放模型的战略价值与安全基石：Reflection AI联合创始人兼CEO Misha Laskin强调了开放模型在当前AI生态中的战略必要性。他指出，移除网络攻击能力的同时也削弱了防御能力，而目前少数封闭实验室的安全研究人员难以全面覆盖AI系统可能带来的非预期后果。Misha援引了一个实际案例：一个强大的封闭模型被攻击后，其所属公司最终只能依靠开放模型来保护自身。这印证了“林纳斯定律”（Linus's Law）在AI领域的适用性——即“足够多的眼睛能让所有漏洞变得显而易见”，这同样适用于AI的安全漏洞。Reflection AI的使命正是构建前沿开放智能，并使其广泛可及，以期通过开放性提升整个AI生态的安全性和韧性。
  • Reflection AI的极速成长与多维挑战：在过去12个月里，Reflection AI经历了一场“边飞边造飞机”的极速冲刺。公司团队从约30人迅速扩张到约300人，旨在建立一个能够开发前沿开放智能的实验室。Misha指出，构建此类模型并非单一因素的挑战，而是计算资源、顶尖人才、海量数据和基础设施建设等多个方面都必须“做对30件事”的系统性工程。他以自己在Google DeepMind的经历为例，强调了大型实验室多年积累的基础设施和工具，对于初创公司而言都需要从零开始搭建。尽管挑战重重，Reflection AI已成功训练并发布了其首个开放模型“Beam”，标志着其在开放智能领域的初步成果。
  • 从强化学习到全栈开放模型：战略转折点：Reflection AI成立之初，Misha和联合创始人Yans（DeepMind AlphaGo核心贡献者）的设想是利用强化学习（RL）将早期的聊天模型（如Gemini 1/1.5时代）转化为更具“智能体”（agentic）能力的系统，并计划基于当时已出现的开放模型（如Mistral、Llama 2）进行研究。然而，RL技术的发展速度超出了他们的预期。更重要的是，他们很快意识到西方市场缺乏高质量的开放模型作为基础，且预训练与强化学习的结合比原先设想的更为紧密。为了实现RL的最佳效果，公司必须端到端地构建自己的基础模型。地缘政治和企业层面的考量也促使Reflection AI做出了这一关键的战略调整，从单纯的RL研究转向了全栈开放模型的开发。
  • 前沿AI训练的资本投入与规模极限：传统观点认为，前沿AI模型的预训练成本高昂，几乎难以承受。Misha揭示了这一领域资本投入的惊人增长：大约18个月前，达到前沿水平需要数亿美元；6个月前，这一数字已飙升至数十亿美元；而展望明年，预计将达到数百亿美元的量级。这种指数级增长与芯片技术（如从H100到Blackwell）的快速迭代和所需计算集群规模（例如从10万个H100到10万个Blackwell）紧密相关。Misha认为，这种资本投入最终会触及一个“渐近线”，因为相对于这些模型可能产生的经济价值，投入不可能无限增长，企业和投资者将面临投资回报的现实考量。
  • 效率提升：AI模型自我进化的新范式：尽管前沿AI训练的资本投入巨大，但Misha指出，AI模型训练的效率正在显著提升，这可能是突破成本瓶颈的关键。一个核心因素是AI模型本身正在成为帮助构建和改进自身的新工具。他提到，在纯粹由人类研究者推动的阶段，每年约能实现7倍的计算效率提升（通过预训练损失的降低来衡量，即用更少的计算资源达到相同的性能）。随着模型开始辅助自身开发，这一效率提升的速度可能更快。Misha还强调，对于像Reflection AI这样的公司，追赶前沿比开创绝对前沿更具资本效率，因为他们可以专注于执行已知有效的方法，而非进行大量的探索性研究。

本期播客深入探讨了传奇投资者约翰·阿米蒂奇（John Armitage）的投资智慧、主动型基金经理面临的市场挑战、全球股东权利的衰退趋势，以及感恩在个人和职业生活中的重要性。它不仅为投资者提供了宝贵的洞察，也为寻求职业发展建议、关注商业伦理和个人成长的听众带来了深刻启示。

  • 约翰·阿米蒂奇：塑造投资大师的导师与贵人：约翰·阿米蒂奇对挪威主权财富基金CEO尼古拉·坦根（Nicolai Tangen）的职业生涯产生了深远影响。他不仅是坦根担任分析师时的最大客户，更是其长达五年的直属上司，手把手教授了坦根如何深入分析公司。阿米蒂奇被坦根誉为“3A级人物”，拥有极高的荣誉感和正直品格。在坦根创立AKO资本时，阿米蒂奇及其同事比尔·博林格（Bill Bollinger）的信任和背书至关重要，他们的推荐使得AKO资本得以顺利起步。坦根强调，没有阿米蒂奇的帮助，他不可能取得今天的成就，这凸显了导师在个人成长和事业发展中的关键作用。
  • 阿米蒂奇的投资哲学：深度分析与运营杠杆：阿米蒂奇的投资方法以严谨、好奇和善于提问著称。他尤其擅长探究公司成功的深层原因，对损益表进行细致入微的分析，追溯增长的源头、其韧性以及核心驱动因素。他将公司的利润驱动力拆解成各个组成部分，并高度关注“运营杠杆”——即公司在新增销售额中能转化为利润的比例。坦根指出，很少有人真正懂得如何分析运营杠杆及其重要性。此外，阿米蒂奇在构建投资组合方面也极具洞察力，他强调通过多元化配置不同驱动因素的公司，以确保在市场波动时，整个组合不会遭受毁灭性打击。
  • 伟大投资者的共同特质：谦逊、承认错误与自我怀疑：阿米蒂奇在选择管理层时，非常看重他们是否敢于承认错误，因为他认为只有正视并改进错误，公司才能不断进步。坦根也认同这一点，并将其作为面试毕业生的重要问题。阿米蒂奇本人也展现出极度的谦逊和自我怀疑，他每天醒来都会思考自己是否还能再次成功，并持续质疑自己的投资组合和决策。坦根观察到，这种谦逊和自我反思是许多伟大投资者（包括播客中采访过的其他顶尖专家）的共同特质，尽管他们已取得巨大成功，但仍保持着学习和改进的心态。坦根虽然不至于每天自我怀疑，但也强调持续改进的重要性。
  • 主动管理者的挑战与“永久资本”之辩：当前市场环境下，主动型基金经理创造超额回报（alpha）的难度日益增加。全球资本充裕，顶尖人才云集，所有人都在追逐相同的机会，而人工智能的兴起可能进一步消除过去的许多套利空间。关于“永久资本”的讨论也反映了行业内的分歧。阿米蒂奇认为永久资本是一个“陷阱”，他偏好保持投资的流动性，认为这种随时可能需要清算头寸的压力能带来良好的投资纪律。然而，坦根则认为拥有相对永久的资本通常更有利，因为它能减轻基金经理对业务持续性的担忧，使其能够更专注于长期投资。这与比尔·阿克曼（Bill Ackman）等寻求永久资本的策略形成了对比。
  • 股东权利的衰落：对公司治理与投资者利益的冲击：坦根指出，近年来全球范围内的股东权利正在急剧恶化，尤其是在一些新上市的公司中。创始人往往通过多重投票权结构，使得一股拥有多票，从而削弱了普通股东的影响力。股东在董事会组成、问责管理层等方面的权利受到限制，甚至无法有效罢免不称职的董事会成员。这种趋势部分源于各国和各证券交易所之间为吸引公司上市而展开的竞争，例如一些欧洲国家（如荷兰阿姆斯特丹）为了吸引企业，可能会放松监管要求。股东权利的衰退对投资者而言是负面的，因为它阻碍了投资者行使所有权、参与公司治理，并推动公司在道德框架下运营的能力。

  • 微观赋能：AI如何助力企业增长与就业：与宏观担忧形成对比，Daniel Priestley从中小企业视角提供了乐观展望。他认为AI能让企业变得“更好”，而非仅仅“更便宜”。例如，AI可以优化营销、法律合同等环节，提升企业效率，从而创造更多高价值的就业机会。他以自己的公司为例，通过AI提升预约效率，反而雇佣了更多销售人员进行最终的客户沟通。他还分享了一个英国北部视频制作机构的案例：一对夫妇利用AI开发了一款自动化脚本软件，在四个月内吸引了1500名客户，并计划招聘10名员工，这在没有AI的情况下是不可想象的。
  • 竞争策略：更便宜还是更优秀？：播客深入探讨了企业在AI时代面临的战略选择：是利用AI削减成本，追求“更便宜”，还是赋能员工，追求“更优秀”？Nick Hanhua指出，一个熟练运用AI工具的员工可能抵得上五个人，企业可以选择裁员以降低成本，也可以选择保留并培训员工，让他们发挥五倍的效率，从而在竞争中脱颖而出。他援引计算器和电脑普及的历史经验，认为这些技术并未减少工作总量，反而增加了工作内容和复杂性。医生在AI的辅助下，将成为“更好的医生”，而非被取代。

The Evolution of Private Credit: Part 2 - [Business Breakdowns, EP.164]

原链接：https://joincolossus.com/episodes/66019922/clarkson-a-primer-on-private-credit-part-2

本期播客深入探讨了私募信贷市场的历史演变、核心运作机制，特别是商业发展公司（BDCs）在其中扮演的关键角色，以及该市场如何应对金融危机和利率上升等宏观挑战。对于希望理解私募信贷作为一种资产类别如何崛起、其结构性优势以及未来发展趋势的专业投资者和金融从业者而言，本期节目提供了宝贵的深度洞察。

  • 私募信贷的演进与银行的共生关系：本期节目作为私募信贷系列节目的第二部分，由Prosek Partners的董事总经理Josh Clarkson主讲，将讨论重点从第一部分的供需动态和监管影响，转向了私募信贷市场的历史、其主要载体以及在压力时期的表现。历史上，人寿保险公司曾是主要的信贷提供者。随着时间的推移，银行在信贷市场中占据主导地位。然而，私募信贷并非完全与银行对立，两者之间存在复杂的竞争与合作关系。私募信贷基金通常能提供更高的交易确定性和更快的执行速度，这使其在某些交易中比传统银行更具优势，尤其是在中小型企业融资领域，私募信贷填补了银行因监管收紧而留下的空白。
  • 商业发展公司（BDCs）的崛起与影响：商业发展公司（BDCs）是私募信贷市场中一个至关重要的组成部分。BDCs的设立旨在向中小型企业提供融资，并允许普通投资者参与到通常只有机构投资者才能接触到的私募信贷市场。它们通过向符合特定条件的企业提供债务和股权融资，从而促进经济发展。BDCs的演变深刻影响了私募信贷市场的格局，它们为投资者提供了流动性相对较好的私募信贷敞口，并推动了该资产类别的普及。节目详细探讨了BDCs的运作机制、杠杆使用方式以及它们如何通过不同的结构和策略来满足市场需求。
  • 金融危机：私募信贷的转折点：2008年的全球金融危机是私募信贷市场发展的一个关键转折点。危机爆发后，银行体系面临严格的监管审查和资本要求，导致它们大幅缩减了对中小型企业的贷款业务，尤其是在杠杆贷款市场。这一监管真空为私募信贷基金的蓬勃发展创造了前所未有的机遇。私募信贷基金凭借其更灵活的资本结构、更快的决策流程以及直接与借款人建立关系的模式，迅速填补了银行撤退后留下的市场空白。危机不仅加速了私募信贷的崛起，也使其成为金融体系中不可或缺的一部分，证明了其在市场压力下的韧性。
  • BDCs的多元化策略与估值考量：BDCs在今天的私募信贷格局中扮演着核心角色，但其内部也存在显著差异。节目区分了公开上市的BDCs和非上市的私人BDCs。公开BDCs通常具有更高的流动性，但其股价可能受到市场情绪和宏观经济因素的波动影响；私人BDCs则可能提供更稳定的回报，但流动性较低。此外，不同的BDCs会采用多样化的投资策略，例如专注于特定行业、债务类型（如第一留置权贷款、次级债）或地理区域。投资者在评估BDCs时，需要深入理解其复杂的财务指标和估值方法，包括净资产价值（NAV）、股息收益率以及管理费结构等，以做出明智的投资决策。
  • 利率上升环境下的机遇与挑战：在利率上升的环境下，私募信贷市场展现出独特的适应性和机遇。由于私募信贷产品通常采用浮动利率，这意味着当基准利率（如SOFR或Term SOFR）上升时，贷款的利息收入也会随之增加，从而为投资者带来更高的收益。这使得私募信贷在通胀和加息周期中具有一定的对冲能力。然而，利率上升也可能增加借款企业的偿债压力，从而提高违约风险。私募信贷基金需要通过严格的信用分析、多元化的投资组合以及与借款人紧密合作来管理这些风险，确保在变化的市场环境中保持稳健的投资表现。
