Vanguard

来源：Acquired

原链接：https://www.acquired.fm/episodes/vanguard

本期节目深入探讨了Vanguard，这家管理着数万亿美元资产、以独特客户所有制颠覆华尔街的金融巨头，揭示了其创始人Jack Bogle如何为普通投资者节省万亿费用，并彻底改变了投资格局的传奇故事。适合所有对个人财富管理、金融创新和商业伦理感兴趣的中文读者。

  • Vanguard是美国最大的指数基金提供商，管理着超过10万亿美元的被动指数基金，平均持有标普500公司近10%的股份，与BlackRock、State Street等同行共同拥有美国股市24%的份额，对全球经济产生巨大影响。
  • Vanguard拥有独特的客户所有制结构：它由其客户独家拥有，不公开上市，没有外部股东，甚至CEO也没有股权，其产品设计和运营目标只为客户利益服务，被主持人形容为一种“共产主义资本主义”。
  • 创始人Jack Bogle是Vanguard的灵魂人物，他是一位特立独行、固执己见的远见者。通过Vanguard的低成本策略，他为投资者节省了超过5000亿美元的费用，并迫使整个行业降费，总计为投资者创造了高达1万亿美元的财富转移。
  • Bogle的早年经历充满挑战：他出生于1929年大萧条前夕的富裕家庭，但随后家道中落，在贫困中长大。他通过奖学金进入普林斯顿大学，其毕业论文《投资公司的经济作用》已提出降低费用以最大化基金持有人回报的理念，为他未来的事业埋下伏笔。
  • Bogle毕业后加入以保守和平衡投资著称的Wellington Management，并于35岁成为总裁。然而，1960年代中期，以Fidelity为代表的激进“Go-Go”投资风格兴起，Wellington的保守策略逐渐失势。

The Plan to Make American Crime Obsolete

来源：The a16z Show

原链接：https://a16z.simplecast.com/episodes/the-plan-to-make-american-crime-obsolete-kFoaNrAU

本期节目深入探讨了美国公共安全领域如何通过部署尖端技术（如无人机、AI分析和数据共享）来应对日益复杂的犯罪挑战、提升警务效率并关怀一线人员身心健康，特别适合关注科技创新在社会治理中应用的企业家、政策制定者和公众。

  • 技术应对警力短缺与职业倦怠：面对警力不足、警员倦怠和工作复杂性增加的挑战，节目强调了利用先进技术提升公共安全效率和保障警员福祉的必要性。
  • 无人机成为执法新常态：无人机正迅速成为响应911报警、追踪嫌疑车辆（如Amber Alert）、提供实时态势感知（例如区分扫帚和霰弹枪）的关键工具，其部署的普及被认为是不可避免的趋势，且比传统直升机更具可持续性。
  • 多传感器数据融合提升犯罪预防：Flock Safety等公司通过整合车牌识别摄像头、枪声检测器和无人机等多种传感器数据，能够实时识别可疑车辆或事件，并迅速采取行动，从而实现更高效的犯罪预防和追捕。
  • 身体佩戴摄像头分析与警员心理健康：身体佩戴摄像头不仅提供执法记录，其后台分析技术还能监测警员与公众的互动行为、评估警员倦怠风险，并为心理健康干预（如休假）提供依据，从而优化警员表现和满意度。
  • 国际情报共享与AI辅助预防犯罪：节目强调了通过融合中心（如亚利桑那反恐中心）进行国内及国际（如与墨西哥、阿联酋等）情报共享的重要性，利用AI分析趋势，旨在将犯罪活动在萌芽阶段就予以阻止。

141. Freda的投资札记第2集：Tokenmaxxing、把电机塞进蒸汽机、接力赛变篮球赛、孤独、人的连接

来源：张小珺Jùn｜商业访谈录

原链接：https://www.xiaoyuzhoufm.com/episode/6a09d58b1b7bd502955258ab?utm_source=rss

本期节目深入探讨了AI时代的投资逻辑、技术演进和市场格局，特别适合关注AI商业模式、技术趋势及投资策略的专业人士和对AI发展感到焦虑的普通听众。如果只看三点：1. AI服务收费模式正从按token转向按“效果付费”。2. Coding Agent成熟启动AI训练AI的“递归式自我改进”循环，领先优势将更难撼动。3. AI市场规模被严重低估，其潜力在于自动化所有白领工作。

  • AI时代的“token”作为能耗产出比（dollar per token）易误导，关键在于“token per task”的效率差异巨大，而非消耗量越多越好，因为不同模型完成同一任务所需的token量可能相差几十甚至上百倍。
  • 尽管AI模型效率将提升，但因用户和任务数激增，AI总投入会持续增长。目前头部公司AI支出占EBITDA的1-2%，仍可控，但行业早期存在显著的token消耗浪费。
  • AI服务将从按token消耗转向按“效果付费”，如AI客服公司Sierra已采用按问题解决率收费，这能更好地对齐客户与供应商利益。但创意类等难以量化的场景可能仍维持token收费。
  • 随着Coding Agent的成熟，AI训练AI的“递归式自我改进”循环已启动，可能导致领先者优势迅速扩大，形成难以追赶的壁垒，这一转折点可能始于2024年初。
  • Meta等大公司斥巨资使用外部AI模型，表明快速迭代能力已成为核心竞争力，没有AI支持将导致开发速度大幅落后。
